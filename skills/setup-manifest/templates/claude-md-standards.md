## Standards

This repo uses the `architect` plugin. Reference files live under `docs/project-manifest/`. Read the matching file **before** doing the work it covers.

- **Git branching & PRs** → `docs/project-manifest/branching-and-pr.md`
  Read before: creating a branch, committing, opening or updating a PR.
- **Folder structure** → `docs/project-manifest/folder-structure.md`
  Read before: creating, moving or renaming a file or folder, scaffolding a module.
- **Coding standards** → `docs/project-manifest/coding-standards.md`
  Read before: writing or editing code.
- **Design system** → `docs/project-manifest/design-system.md`
  Read before: building or changing UI.

A rule applies only while its file exists.
