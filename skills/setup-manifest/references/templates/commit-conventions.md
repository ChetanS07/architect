# Commit conventions

Commit rules for the workflow in [`branching-and-pr.md`](../branching-and-pr.md).

- One coherent change per commit; unrelated edits go in separate commits.
- Title in the imperative, under 90 characters: `Add rate limiting to login endpoint`. Every title names the change, so `fixed stuff` or `WIP` never appear. Wrap any body at 90.
- If the work has a task ID, add the trailer `Task: <id>`. Use only IDs the human or the issue gave you.
